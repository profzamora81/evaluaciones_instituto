Observación Importante

Esta prueba evalúa los contenidos prácticos de mantenimiento lógico, comandos Bash en Linux Q4OS/Debian, firewall UFW y auditoría con journalctl. La resolución debe ser individual y estrictamente personal.

Datos del Estudiante

FASE I: Mantenimiento Lógico y Diagnóstico de Sistema (10 Puntos)

Serie I: Opción Múltiple (Comandos y Diagnóstico de Hardware)

5 Puntos

Instrucciones: Lea atentamente cada enunciado y seleccione la opción correcta. (Valor: 5 ítems a 1 pt c/u).

1. ¿Por qué es crítico NUNCA ejecutar el comando fsck sobre una partición de disco que se encuentra montada y activa en el sistema?

2. Al ejecutar el comando free -h en la terminal, ¿qué representa el valor reflejado en el espacio de intercambio "Swap"?

3. ¿Cuál es el propósito del comando sudo apt autoremove -y en distribuciones GNU/Linux basadas en Debian/Q4OS?

4. ¿Cuál de los siguientes comandos permite auditar únicamente las alertas críticas y errores graves del sistema filtrados mediante journalctl?

5. Al monitorear el sistema de manera interactiva con htop, ¿qué acción o tecla permite enviar una señal de terminación forzada (Kill) a un proceso bloqueado?

Serie II: Términos Conceptuales y Servicios de Sistema

5 Puntos

Instrucciones: Selecciona del menú desplegable la herramienta o término técnico que corresponde a cada definición. (Valor: 5 ítems a 1 pt c/u).

1. Herramienta utilitaria de consulta de registros centralizados y auditoría del sistema de inicio systemd.

2. Cortafuegos simplificado en Linux diseñado para gestionar políticas de seguridad de red y reglas de filtrado de puertos.

3. Comando CLI utilizado para inspeccionar, iniciar, detener y deshabilitar servicios que se ejecutan en segundo plano.

4. Software de mantenimiento y optimización automatizada para la limpieza profunda de cachés, temporales del sistema y cookies.

5. Base de datos jerárquica en Windows que almacena las configuraciones globales, perfiles de usuario y claves de arranque del sistema.

FASE II: Seguridad Perimetral, Logs y Comandos Bash (10 Puntos)

Serie III: Análisis Técnico de Seguridad y Mantenimiento

5 Puntos

Instrucciones: Analice con criterio técnico los siguientes escenarios de administración de servidores e instalación. (Valor: 5 ítems a 1 pt c/u).

1. ¿Cuál es el comando exacto en UFW para habilitar el tráfico seguro de navegación web a través del puerto 443 (HTTPS)?

2. Para bloquear de forma inmediata todo el tráfico proveniente de la dirección IP sospechosa 192.168.1.15, ¿qué regla de UFW debe ejecutarse?

3. Ante una interrupción eléctrica en el taller que provoca un error de "broken packages" en Q4OS, ¿cuál es el comando nativo de reparación de dependencias?

4. ¿Qué comando de diagnóstico de almacenamiento se utiliza al inicio y final de una rutina de depuración para verificar el espacio en formato legible humanamente (-h)?

5. ¿Cuál es la fórmula matemática utilizada para calcular la tasa porcentual de recuperación de espacio en disco ($R_d$) tras la depuración lógica?

Serie IV: Completación de Comandos Bash y Scripts de Mantenimiento

5 Puntos

Instrucciones: Seleccione la palabra clave o comando faltante para completar la sintaxis en la terminal Bash. (Valor: 5 ítems a 1 pt c/u).

Ítem 1: Secuencia Completa de Mantenimiento APT bash 
# Actualizar repositorios e índices de paquetes
sudo apt 

# Descargar e instalar las actualizaciones de software disponibles
sudo apt 

# Limpiar la caché de paquetes de instalación antiguos almacenados en disco
sudo apt clean
Ítem 2: Activación y Verificación del Cortafuegos UFW bash 
# Habilitar el cortafuegos perimetral local
sudo ufw 

# Consultar el estado del firewall y sus reglas configuradas
sudo ufw status verbose
Ítem 3: Detención y Desactivación de Servicios Innecesarios bash 
# Detener el servicio de impresión CUPS en tiempo de ejecución
sudo systemctl stop cups.service

# Deshabilitar el servicio para que NO inicie automáticamente en el arranque
sudo systemctl  cups.service
Ítem 4: Auditoría de Logs por Servicio Específico en journalctl bash 
# Auditar únicamente los registros generados por el servicio de tareas programadas (Cron)
journalctl -u
Ítem 5: Depuración Segura de Archivos Temporales en Linux bash 
# Verificar el tamaño total ocupado por el directorio de temporales del sistema
du -sh
